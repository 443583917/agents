## Day 1：Hello World——触摸 SDK（1_lab1.ipynb）

**目标：** 用最少代码跑通第一个 Agent，建立对 API 的直觉。

**核心 API：**

```python
from agents import Agent, Runner, trace

agent = Agent(
    name="Jokester",
    instructions="You are a joke teller",
    model="gpt-4o-mini"
)

with trace("Telling a joke"):
    result = await Runner.run(agent, "Tell a joke about AI")
    print(result.final_output)
```

**你要搞懂：**
1. `Agent` 的三个必填参数：`name`（名字）、`instructions`（系统指令）、`model`（模型）
2. `Runner.run()` 是异步的，必须用 `await`
3. `result.final_output` 拿到最终文本输出
4. `trace` 上下文管理器记录完整运行过程，去 https://platform.openai.com/traces 查看

**用 DeepSeek 跑这个 Lab：**

```python
from agents import Agent, Runner, OpenAIChatCompletionsModel
from openai import AsyncOpenAI
import os

client = AsyncOpenAI(
    base_url="https://api.deepseek.com",
    api_key=os.getenv("DEEPSEEK_API_KEY")
)
model = OpenAIChatCompletionsModel(
    model="deepseek-chat",
    openai_client=client
)

agent = Agent(
    name="Jokester",
    instructions="You are a joke teller",
    model=model
)

result = await Runner.run(agent, "Tell a joke about AI")
print(result.final_output)
```

## Day 2：第一个 Agent 项目——冷销售邮件系统（2_lab2.ipynb）

**目标：** 构建一个真实的业务工作流，掌握 Tool、Agent-as-Tool、Handoff 三种协作机制。

### 项目场景

为虚构公司 **"ComplAI"**（SOC2 合规自动化 SaaS）生成冷销售邮件。

### 阶段 1：并行多 Agent

3 个销售 Agent，不同"人格"，用 `asyncio.gather()` 并行生成邮件：

```python
# 专业风格
professional_agent = Agent(
    name="Professional",
    instructions="You are a professional B2B sales rep..."
)
# 有趣风格
engaging_agent = Agent(
    name="Engaging",
    instructions="You write engaging and friendly sales emails..."
)
# 忙碌高管风格
busy_agent = Agent(
    name="Busy",
    instructions="You write extremely concise emails for busy execs..."
)

# 并行运行
results = await asyncio.gather(
    Runner.run(professional_agent, prompt),
    Runner.run(engaging_agent, prompt),
    Runner.run(busy_agent, prompt)
)
```

### 阶段 2：Tool（函数工具）

用 `@function_tool` 把 Python 函数暴露给 Agent：

```python
@function_tool
def send_email(recipient: str, subject: str, body: str) -> str:
    """Send an email to a recipient"""
    # 调用 SendGrid API
    return "Email sent successfully"
```

Agent 会自动决定何时调用这个函数——你不需要写调用逻辑。

### 阶段 3：Agent-as-Tool + Handoff

把一个 Agent 包装成另一个 Agent 的工具：

```python
# Sales Manager 把销售 Agent 当作工具调用
sales_manager = Agent(
    name="Sales Manager",
    tools=[professional_agent.as_tool(), engaging_agent.as_tool()]
)
```

Handoff：Sales Manager 写完邮件后转给 Email Manager 发送：

```python
email_manager = Agent(
    name="Email Manager",
    instructions="Add subject line and HTML formatting, then send"
)

sales_manager = Agent(
    name="Sales Manager",
    handoffs=[email_manager]  # 可以转交任务
)
```

**你要搞懂：**
1. `@function_tool` 怎么让 LLM 调用你的 Python 代码
2. `.as_tool()` 怎么把 Agent 变成可组合的组件
3. `handoffs` 怎么实现 Agent 之间的任务委派
4. `asyncio.gather()` 并行执行多个 Agent

### Structured Output（结构化输出）

用 Pydantic 约束 Agent 的输出格式——不再拿回来一个自由文本，而是有类型的数据：

```python
from pydantic import BaseModel

class EmailOutput(BaseModel):
    subject: str
    body: str
    tone: str

agent = Agent(
    name="Email Writer",
    output_type=EmailOutput  # Agent 必须返回这个结构
)

result = await Runner.run(agent, prompt)
email: EmailOutput = result.final_output_as(EmailOutput)
print(email.subject)  # 类型安全，IDE 有自动补全
```

### Guardrail（安全检查）

输入 Guardrail 在 Agent 执行前拦截不合规消息：

```python
from agents import input_guardrail, GuardrailFunctionOutput

@input_guardrail
async def check_personal_name(ctx, agent, input):
    """拒绝包含人名的消息（防止针对性攻击）"""
    # 检查逻辑
    if contains_personal_name(input):
        return GuardrailFunctionOutput(
            output_info="输入包含人名",
            tripwire_triggered=True  # 触发拦截
        )
    return GuardrailFunctionOutput(tripwire_triggered=False)

agent = Agent(
    name="Safe Agent",
    input_guardrails=[check_personal_name]
)
```

**你要搞懂：**
1. `OpenAIChatCompletionsModel` 怎么桥接任意 OpenAI 兼容 API
2. Pydantic `BaseModel` + `output_type` 怎么做到类型安全
3. `@input_guardrail` 的执行时机和 `tripwire_triggered` 的含义

## Day 4：Deep Research——深度研究 Agent（4_lab4.ipynb + deep_research/）

**目标：** 构建一个完整的端到端 Agent 应用——输入一个话题，自动搜资料、写报告、发邮件。

### 管线架构

```
用户输入话题
    │
    ▼
Planner Agent ──► 规划 5 个搜索方向（Structured Output）
    │
    ▼
Search Agent × 5 ──► 并行搜索网页（WebSearchTool）
    │
    ▼
Writer Agent ──► 合成为 5-10 页 markdown 报告
    │
    ▼
Email Agent ──► 发送 HTML 格式邮件
```

### 核心代码（notebook 版）

```python
# 1. 规划搜索
class WebSearchItem(BaseModel):
    query: str
    reason: str

class WebSearchPlan(BaseModel):
    searches: list[WebSearchItem]

planner = Agent(
    name="Planner",
    instructions="Plan web searches for a research topic",
    output_type=WebSearchPlan
)

# 2. 执行搜索
search_agent = Agent(
    name="Searcher",
    tools=[WebSearchTool()],  # OpenAI 托管搜索
    instructions="Search the web and summarize results"
)

# 3. 写报告
writer = Agent(
    name="Writer",
    instructions="Write a comprehensive markdown report",
    output_type=ReportData
)

# 4. 编排
plan = await Runner.run(planner, topic)
searches = await asyncio.gather(*[
    Runner.run(search_agent, item.query)
    for item in plan.final_output.searches
])
report = await Runner.run(writer, combine(searches))
```

## 关键概念速查表

| 概念 | API | 用途 |
|------|-----|------|
| 创建 Agent | `Agent(name, instructions, model)` | 定义一个 AI 角色 |
| 运行 Agent | `await Runner.run(agent, prompt)` | 执行 Agent |
| 流式输出 | `Runner.run_streamed(agent, prompt)` | 逐字输出 |
| 函数工具 | `@function_tool` | 把函数暴露给 Agent |
| Agent 作工具 | `agent.as_tool()` | 嵌套 Agent |
| 任务委派 | `handoffs=[other_agent]` | Agent 间转交 |
| 结构化输出 | `output_type=PydanticModel` | 类型安全的输出 |
| 输入检查 | `@input_guardrail` | 执行前拦截 |
| 追踪 | `with trace("name"):` | 可视化运行轨迹 |
| 多模型 | `OpenAIChatCompletionsModel` | 用 DeepSeek/Gemini 等 |
| 搜索工具 | `WebSearchTool()` | OpenAI 托管网页搜索 |

## 常见问题

**Q: DeepSeek 能跑所有 Lab 吗？**
A: 能。Lab 1-3 完全兼容。Lab 4 的 `WebSearchTool` 是 OpenAI 托管服务，用 DeepSeek 无法调用，但可以用免费搜索 API 替代（如 DuckDuckGo）。

**Q: `await` 报错怎么办？**
A: 确保 cell 在 async 上下文中。notebook 里直接用裸 `await`，Python 脚本里要放在 `async def main()` 中再用 `asyncio.run(main())`。

**Q: SendGrid 配置太麻烦，能跳过吗？**
A: 可以。把 `send_email` 函数改成 `print()` 输出即可跑通逻辑。

**Q: trace 在哪看？**
A: https://platform.openai.com/traces —— 只有用 OpenAI 模型才有。DeepSeek 的 trace 需要其他方案（如 LangSmith）。
