## 三、运行代码

1. 点击第一个代码单元格（灰色背景的那个）
2. 按 `Shift + Enter` — 执行这个单元格
3. 观察输出结果

每个单元格都要这样逐个执行，**顺序很重要**，因为后面的单元格依赖前面定义的变量。

## 四、Notebook 常用操作

| 操作 | 快捷键 |
|------|--------|
| 执行当前单元格 | `Shift + Enter` |
| 执行当前单元格但不跳走 | `Ctrl + Enter` |
| 在上方插入新单元格 | `Esc` 然后按 `A` |
| 在下方插入新单元格 | `Esc` 然后按 `B` |
| 删除当前单元格 | `Esc` 然后按 `D` 两次 |
| 重启 Kernel（清空变量） | 点击右上角"Restart"按钮 |

## 五、用 DeepSeek 调用 LLM（第一个实验）

你已经配置了 DeepSeek API。运行以下代码测试：

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

client = OpenAI(
    base_url="https://api.deepseek.com",
    api_key=os.getenv("DEEPSEEK_API_KEY")
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是一个有帮助的助手。"},
        {"role": "user", "content": "用一句话介绍什么是 Agent。"}
    ]
)

print(response.choices[0].message.content)
```

在 notebook 中新建一个代码单元格，粘贴上面代码，按 `Shift+Enter` 运行。

## 七、常见问题

### Q: 运行代码报 `NameError: xxx is not defined`
说明你没有按顺序执行前面的单元格。从 notebook 顶部重新逐个执行。

### Q: 运行代码报 `ModuleNotFoundError`
在终端运行 `uv sync` 确保所有包已安装。

### Q: 想验证 API 是否正常
```bash
uv run python -c "
from openai import OpenAI
from dotenv import load_dotenv
import os
load_dotenv()
c = OpenAI(base_url='https://api.deepseek.com', api_key=os.getenv('DEEPSEEK_API_KEY'))
r = c.chat.completions.create(model='deepseek-chat', messages=[{'role':'user','content':'hi'}])
print(r.choices[0].message.content)
"
```
输出 `Hi` 之类的内容即正常。
