## Day 3-5：OpenAI Agents SDK（核心框架，最重要！）

这个 SDK 把 Agent Loop 封装成了工业级原语。**这是你 10 天里最重要的 36 小时。**

打开 `2_openai/` 文件夹：

| Lab | 核心概念 | 时间 |
|-----|---------|------|
| `1_lab1.ipynb` | Agent、Runner、同步/异步运行 | 4h |
| `2_lab2.ipynb` | **Tool 深度**：function_tool 装饰器、自定义 tool 类 | 6h |
| `3_lab3.ipynb` | **Handoff**：Agent 之间相互委托任务 | 8h |
| `4_lab4.ipynb` | **Guardrail**：输入/输出安全检查 + **Tracing**：全链路追踪 | 8h |
| `deep_research/` 文件夹 | **完整项目**：深度研究 Agent（搜资料→分析→写报告） | 6h |
| 自主练习 | 写一个自己的 Agent，比如"Go 语言面试辅导" | 4h |

**关键概念对照：**

| OpenAI SDK 概念 | 解释 |
|----------------|------|
| Agent | 一个 AI 角色，有名字、指令、可用的工具 |
| Tool | LLM 可以调用的函数（查天气、搜网页、读文件等） |
| Handoff | A Agent 把对话转给 B Agent（比如客服转给技术） |
| Guardrail | 安全检查：输入过滤 + 输出校验 |
| Tracing | 查看这次 Agent 运行的完整过程 |

### 用 DeepSeek 替代 OpenAI（省钱）

你已经在 `.env` 里配置好了。在 SDK 中使用 DeepSeek 需要 3 步：

```python
from agents import Agent, OpenAIChatCompletionsModel
from openai import AsyncOpenAI
import os
from dotenv import load_dotenv
load_dotenv()

# 步骤 1：创建指向 DeepSeek 的客户端
deepseek_client = AsyncOpenAI(
    base_url="https://api.deepseek.com",       # 注意是 /v1 还是不带
    api_key=os.getenv("DEEPSEEK_API_KEY")
)

# 步骤 2：创建模型对象
deepseek_model = OpenAIChatCompletionsModel(
    model="deepseek-chat",
    openai_client=deepseek_client
)

# 步骤 3：创建 Agent 时指定这个模型
agent = Agent(
    name="我的助手",
    instructions="你是一个有帮助的助手。",
    model=deepseek_model  # 用 DeepSeek 替代 GPT
)
```

## Day 6：CrewAI（多 Agent 角色协作）

解决的是"怎么让多个 Agent 像团队一样工作"。

打开 `3_crew/` 文件夹：

| 项目 | 你学到什么 | 时间 |
|------|-----------|------|
| `debate/` | 两个 Agent 辩论——理解 Role/Goal/Backstory | 3h |
| `engineering_team/` | 工程团队：需求→设计→实现→审查 | 5h |
| `stock_picker/` | 金融分析 Agent，带数据工具 | 4h |
| `financial_researcher/` | 深度研究→分析→报告生成 | 3h |
| `coder/` | 代码生成 Agent | 3h |

**CrewAI 核心概念：**

```python
# Agent 有 3 个核心属性
Agent(
    role="研究员",          # 角色
    goal="发现突破性洞见",    # 目标
    backstory="20年经验...",  # 背景故事（影响行为风格）
    tools=[搜索工具],
)

# Task 有明确的输入输出
Task(
    description="研究主题 X",
    expected_output="500字报告",
    agent=researcher,
)

# Crew 编排任务管线
Crew(agents=[...], tasks=[...], process=Process.sequential)
```

**什么时候用 CrewAI：** 当你需要固定的工作管线（A→B→C），而不是自由对话。

## Day 7-8：LangGraph（状态图编排）

把 Agent 工作流建模成**有向图**。对后端程序员最自然的框架。

打开 `4_langgraph/` 文件夹：

| Lab | 核心概念 | 时间 |
|-----|---------|------|
| `1_lab1.ipynb` | StateGraph、Node、Edge 基础 | 4h |
| `2_lab2.ipynb` | 条件路由（if/else 在图里）、循环 | 6h |
| `3_lab3.ipynb` | **Human-in-loop**（人工审批节点）+ Checkpoint（状态快照） | 8h |
| `4_lab4.ipynb` | 多 Agent 图、子图嵌套 | 8h |
| `sidekick.py` | **完整项目**：AI 助手应用 | 6h |
| 自主练习 | 用 LangGraph 重写一个 Week 2 的 Agent | 4h |

**LangGraph 核心概念：**

```
        ┌──────────┐
        │  START   │
        └────┬─────┘
             ▼
      ┌─────────────┐
      │   agent     │ ←── 处理节点
      └─────┬───────┘
            ▼
      ┌───────────┐
      │  router   │ ←── 条件路由：该走 tools 还是 END？
      └─┬──────┬──┘
        │      │
   tools│      │END
        │      │
    ┌───▼──┐   │
    │tools │───┘
    └──────┘
```

**什么时候用 LangGraph：** 当你需要精确控制 Agent 的每一步流程，需要人工审批，需要状态回滚。

## Day 8-9：AutoGen（分布式多 Agent）

微软的方案，特色是 Agent 间通过消息总线通信，可以跨进程、跨机器。

打开 `5_autogen/` 文件夹：

| Lab | 核心概念 | 时间 |
|-----|---------|------|
| `1_lab1_autogen_agentchat.ipynb` | AgentChat 层——对话式 Agent | 4h |
| `2_lab2_autogen_agentchat.ipynb` | 团队模式：RoundRobin/Selector | 5h |
| `3_lab3_autogen_core.ipynb` | **Core 层**：Topic/Subscription 消息模型 | 5h |
| `4_lab4_autogen_distributed.ipynb` | gRPC 分布式部署 | 4h |

**AutoGen 核心概念：**

```
Agent A ──publish(topic="results")──► Topic: "results"
                                         │
                           ┌─────────────┼─────────────┐
                           ▼             ▼             ▼
                       Agent B       Agent C       Agent D
                     (订阅了该topic的所有Agent都会收到消息)
```

**什么时候用 AutoGen：** 当你的 Agent 需要分布在不同的进程/机器上运行。

## Day 9-10：MCP（Agent 的通用接口协议）

MCP 是把 tool 标准化成"可插拔服务"的协议。像 gRPC 一样定义接口，任何 Agent 都能调用。

打开 `6_mcp/` 文件夹：

| Lab | 核心概念 | 时间 |
|-----|---------|------|
| `1_lab1.ipynb` | MCP 协议基础、JSON-RPC、生命周期 | 3h |
| `2_lab2.ipynb` | 写第一个 MCP Server（工具提供者） | 3h |
| `3_lab3.ipynb` | Resources（数据源）+ Prompts（模板） | 4h |
| `4_lab4.ipynb` | **Trading Floor**：完整多Agent+MCP交易系统 | 4h |
| `5_lab5.ipynb` | 远程 MCP Server、Docker 部署 | 4h |

**MCP 核心概念：**

```
┌──────────────┐  tools/list    ┌──────────────┐
│  Host/Client │◄──────────────►│  MCP Server  │
│  (Cursor/    │  tools/call    │  (你写的工具) │
│   Claude)    │  resources/read│              │
└──────────────┘                └──────────────┘
```
