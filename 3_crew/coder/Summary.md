# 总结文件
1.在安装完需要的环境后通过 crewai create crew my_project 命令创建项目框架
2. 执行流程
┌─────────────────────────────────────────────────────────────────┐
│                        main.py (入口)                           │
│                                                                 │
│  1. 构建 inputs 字典（模板变量）                                  │
│  2. 调用 Crew().crew().kickoff(inputs=...)                      │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                     crew.py (组装中心)                           │
│                                                                 │
│  @CrewBase 类                                                   │
│  ├─ 加载 YAML 配置 (agents.yaml + tasks.yaml)                    │
│  ├─ @agent 方法 → 创建 Agent 实例 → 汇入 self.agents              │
│  ├─ @task  方法 → 创建 Task 实例  → 汇入 self.tasks               │
│  └─ @crew  方法 → Crew(agents, tasks, process) → 返回 Crew 对象  │
│                                                                 │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Crew 执行引擎                                 │
│                                                                 │
│  Process.sequential (串行)          Process.hierarchical (层级)  │
│  ┌──────┐    ┌──────┐    ┌──────┐   ┌──────────────────────┐   │
│  │Task 1│───►│Task 2│───►│Task 3│   │    Manager Agent     │   │
│  └──────┘    └──────┘    └──────┘   │  动态委派任务给专家   │   │
│      │           │           │      └──────────────────────┘   │
│      ▼           ▼           ▼                                  │
│  上下文自动传递给下一个Task                                       │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Agent 执行循环 (Agent Loop)                    │
│                                                                 │
│  每个 Agent 内部：                                               │
│  1. 读取 Task 描述 + 上下文                                      │
│  2. 思考（选择工具 / 生成文本）                                   │
│  3. 行动（调用 Tool 或代码执行）                                  │
│  4. 观察结果                                                     │
│  5. 判断是否完成 → 未完成则回到第2步                              │
│  6. 输出结果                                                     │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
                    ┌──────────────┐
                    │  输出到文件   │
                    │ output/*.md  │
                    │ output/*.txt │
                    └──────────────┘
